# Line Draw & Measure (วาดเส้น & วัดระยะ)

ปลั๊กอิน QGIS สำหรับ **วาดเส้นพร้อมอ่านระยะได้ทันที** — ออกแบบมาสำหรับงานรังวัด/ทำแผนที่
ที่ต้องการเห็นความยาว "แต่ละด้าน" ของเส้นที่วาดเป็นหน่วยเมตรบนแผนที่โดยตรง

> **ผู้พัฒนา:** นายภาคภูมิ สูบกำปัง — วิศวกรรังวัดปฏิบัติการ กองเทคโนโลยีทำแผนที่

---

## ความสามารถ

### 1. วาดเส้นบนแผนที่
- กด **สร้าง Layer เส้น** → ปลั๊กอินสร้างชั้นข้อมูลให้ 2 ชั้น
  - `เส้นที่วาด (Line)` — ชั้นที่วาดจริง (memory layer, CRS ตามโปรเจกต์)
  - `ระยะเส้น (Label)` — ชั้นแสดง label ระยะ (ระบบดูแลให้เอง ไม่ต้องแตะ)
- กด **✎ วาดเส้น** → เข้าโหมดวาดด้วยเครื่องมือ Add Feature มาตรฐานของ QGIS
  - คลิกซ้าย = ลงจุด, คลิกขวา = จบเส้น, วาดได้หลายเส้นในชั้นเดียว
  - เปิด **snapping แบบ vertex** ให้อัตโนมัติ — เคอร์เซอร์ดูดเข้าหามุม/หมุดของชั้นอื่น

### 2. แสดงระยะแต่ละช่วง (หน่วยเมตร)
- ปุ่มเช็ก **"แสดงระยะบนเส้น (เมตร)"**
- แสดงระยะของเส้น **ทีละช่วง** (จุดหักถึงจุดหัก) ไม่ใช่ความยาวรวม
- label วาง **ข้างแนวเส้น เยื้องขึ้น 2 มม.** จึงไม่ทับตัวเส้น และหันตามทิศแผนที่เสมอ
  (ไม่พลิกหัวกลับเวลาวาดเส้นย้อนทาง) พร้อมขอบขาวรอบตัวอักษรให้อ่านออกบนภาพถ่าย
- คำนวณด้วย `QgsDistanceArea` + ellipsoid ของโปรเจกต์ → **เป็นเมตรจริงเสมอ**
  แม้โปรเจกต์จะอยู่บน CRS หน่วยองศา เช่น EPSG:4326
- อัปเดตเองอัตโนมัติเมื่อวาดเส้นเพิ่ม ลากแก้ vertex หรือลบเส้น

### 3. ล็อกระยะ / ล็อกมุม ระหว่างวาด
ยกระบบ **ดิจิไทซ์ขั้นสูง (Advanced Digitizing)** ของ QGIS มาสั่งได้จากในหน้าต่างปลั๊กอินเลย

| ช่อง | ผลลัพธ์ |
|---|---|
| ☐ **ล็อกระยะ** + ช่องตัวเลข | ทุกช่วงที่วาดยาวเท่าค่าที่กรอกเป๊ะ ๆ (ล็อกค้างทุกช่วง ไม่หลุดหลังช่วงแรก) แก้ตัวเลขกลางคันได้ ช่วงถัดไปใช้ค่าใหม่ทันที |
| ☑ **กด Shift ค้างเพื่อล็อกมุม** + ช่ององศา | กด Shift ค้างระหว่างวาด = บังคับแนวเส้นตามองศาที่ตั้ง (สัมพัทธ์กับช่วงก่อนหน้า, ค่าเริ่มต้น 90°) ปล่อยแล้วลากอิสระตามเดิม |
> **แถบดิจิไทซ์ขั้นสูงของ QGIS จะไม่โผล่ขึ้นมาเลยระหว่างใช้ปลั๊กอินนี้** — ปลั๊กอินแยก
> "ระบบล็อก" (`cadEnabled`) ออกจาก "แถบที่เห็นบนจอ" (`setVisible`) แล้วบังคับซ่อนแถบไว้เสมอ
> ทั้งตอนล็อกระยะ ตอนกด Shift ล็อกมุม และตอนสลับเครื่องมือ ระบบล็อกยังทำงานเต็มที่เบื้องหลัง
> (ตอน unload ปลั๊กอินจะคืนสถานะแถบให้เหมือนก่อนเปิด)

ใช้ล็อกระยะ + ล็อกมุมพร้อมกันได้ เช่น ล็อก 20 ม. + Shift (90°) → ได้ช่วงตั้งฉากยาว 20 ม.

> ⚠ ค่าในช่อง "ล็อกระยะ" เป็น **หน่วยแผนที่** ตามระบบของ QGIS (= เมตร เมื่อโปรเจกต์ใช้ CRS หน่วยเมตร
> เช่น EPSG:24047 / UTM) ถ้าโปรเจกต์ไม่ได้ใช้หน่วยเมตร ปลั๊กอินจะเตือนให้ทราบ
> — ส่วน **label ระยะเป็นเมตรจริงเสมอ** ไม่ขึ้นกับ CRS

### 4. แสดง Node ที่จุดหัก
- ปุ่มเช็ก **"แสดง Node ที่จุดหัก"**
- จุดกลมสีแดงขอบขาวที่หัวเส้น ท้ายเส้น และทุกจุดหัก
- ทำด้วย symbol layer ของเส้นเอง จึงติดไปกับเส้นตอนแก้ไข/ย้าย vertex โดยไม่ต้องมีชั้น POINT เพิ่ม

### 5. ขึงแนวตรึง — ตรวจว่าโพลิกอนสองฝั่งอยู่ในแนวเดียวกันมั้ย

แทนที่จะเพ่งด้วยตาว่า "มันตรงกันมั้ย" ส่วนนี้ให้**ตัวเลขที่ใช้อ้างอิงได้**

**ขั้นตอน**
1. กด **✎ ขึงแนว (คลิก 2 จุด)** → คลิก 2 จุดบนแผนที่ (snap เข้าหมุด/มุมแปลงได้) แล้วคลิกขวาจบ
2. ปลั๊กอินยืดแนวออกไป**ทั้งสองด้าน**ให้พาดข้ามจอ (เส้นประฟ้า ชั้น `แนวตรึง (Guide)`)
   — เหมือนขึงเชือกตรึงแนว ไม่ใช่แค่เส้นระหว่างสองจุด
3. เลือก **ชั้น POLYGON** ที่จะตรวจ ตั้ง **ระยะค้นหารอบแนว** และ **ค่าที่ยอมรับ**
4. กด **▶ ตรวจแนว**

**ผลที่ได้** — vertex ที่เยื้องออกนอกแนวเกินค่าที่ยอมรับจะขึ้นเป็นจุดแดงพร้อมป้ายบอกค่า
และมีตารางในหน้าต่างปลั๊กอิน (FID / เยื้อง / ทิศ) เรียงจากเยื้องมากไปน้อย
**ดับเบิลคลิกที่แถว = ซูมไปยังจุดนั้นพร้อมไฮไลต์กะพริบ**

```
        ┌──────────┐         ┌──────────┐
        │ แปลง A   │         │ แปลง B   │
════════●══════════●═════════●══════════●════════  ← แนวที่ขึง (ยืดสุดขอบจอ)
       ผ่าน       +0.004    −0.152 ⚠   ผ่าน
                                └─ เยื้องออกนอกแนว 15 ซม.
```

| ช่อง | ความหมาย |
|---|---|
| **ระยะค้นหารอบแนว** | สนใจเฉพาะ vertex ที่ห่างจากแนวไม่เกินค่านี้ (ไกลกว่านี้ = คนละแนว ไม่ใช่ความผิดพลาด) |
| **ยอมรับเยื้องได้** | เยื้องไม่เกินค่านี้ถือว่ายังอยู่ในแนว — เกินกว่านี้จึงรายงาน |
| **ทิศ ซ้าย/ขวา** | อยู่ฝั่งไหนของแนว เทียบกับทิศที่ขึง (จุดแรก → จุดที่สอง) |

- ค่าเยื้องเป็น **เมตรจริง** (คำนวณเทียบ ellipsoid ของโปรเจกต์) ใช้ได้แม้บน CRS หน่วยองศา
- คำนวณเทียบ **เส้นตรงอนันต์**ที่ลากผ่าน 2 จุดที่ขึง จุดที่อยู่เลยปลายแนวออกไปจึงวัดได้ถูกต้อง
- ขึงแนวใหม่ทับแนวเดิมได้เลย ไม่ต้องกดล้างก่อน (มีแนวได้ทีละแนวเดียว)
- vertex ที่ปิดวงแหวนโพลิกอน (จุดแรกซ้ำท้าย) ถูกกรองออก ไม่รายงานซ้ำ

### 6. อัปเดตปลั๊กอินจาก GitHub
ปุ่ม **อัปเดตปลั๊กอิน** ตรวจเวอร์ชันจาก `metadata.txt` บน GitHub แล้วดาวน์โหลด/ติดตั้งให้
(ติดตั้งเสร็จต้องปิด–เปิด QGIS ใหม่)

---

## การติดตั้ง

1. ดาวน์โหลด/โคลนโฟลเดอร์นี้
2. คัดลอกไปไว้ที่โฟลเดอร์ปลั๊กอินของ QGIS
   ```
   C:\Users\<ชื่อผู้ใช้>\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\
   ```
3. เปิด QGIS → เมนู **ปลั๊กอิน > จัดการและติดตั้งปลั๊กอิน > ติดตั้งแล้ว** → ติ๊กเปิดใช้งาน
4. เปิดหน้าต่างได้จากไอคอนบนทูลบาร์ หรือเมนู **เวกเตอร์ > วาดเส้น & วัดระยะ**

**ความต้องการ:** QGIS 3.28 ขึ้นไป

## โครงสร้างไฟล์

```
__init__.py          จุดเข้า classFactory ของ QGIS
plugin.py            สร้างเมนู/ทูลบาร์ + เปิดหน้าต่าง dock
line_dock.py         หน้าต่างหลัก (UI ทั้งหมด) + การล็อกระยะ/มุม + ปุ่มอัปเดต
line_tools.py        จัดการชั้นเส้น/ชั้น label ระยะ, สไตล์เส้น + จุด Node, คำนวณระยะ
guide_tools.py       ขึงแนวตรึง: ชั้นแนว, ยืดแนวข้ามจอ, วัดระยะเยื้องตั้งฉาก, ชั้นผลตรวจ
update_checker.py    ตรวจเวอร์ชันและติดตั้งอัปเดตจาก GitHub (ทำงานเบื้องหลัง)
metadata.txt         ข้อมูลปลั๊กอิน + เวอร์ชัน + changelog
resources/           ไอคอนปลั๊กอิน
```

## หมายเหตุการใช้งาน

- ชั้น `ระยะเส้น (Label)` ถูกตั้งเป็น **อ่านอย่างเดียว** และถูกสร้างใหม่ทั้งชั้นทุกครั้งที่เส้นเปลี่ยน
  — ไม่ควรแก้ไขเอง ถ้าลบชั้นเส้นทิ้ง ชั้นนี้จะถูกเก็บกวาดตามไปด้วย
- ชั้นข้อมูลเป็น **memory layer** ปิดโปรเจกต์แล้วหาย ถ้าต้องการเก็บถาวรให้ Export
  (คลิกขวาที่ชั้น > ส่งออก > บันทึกเป็น...) เป็น GeoPackage/Shapefile ก่อนปิด
- ระยะที่ label แสดงปัดเป็นทศนิยม 3 ตำแหน่ง (มิลลิเมตร)
